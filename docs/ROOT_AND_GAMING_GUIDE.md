Это исчерпывающее пошаговое руководство, составленное на основе реального успешного взлома и настройки телевизора **LG 43UN71006LB (webOS 5.6.2, прошивка `04.64.00`, SoC k6lp / ARMv7)**. 

Руководство универсально и подходит для большинства моделей **LG Smart TV под управлением webOS 4.0 – 11 (webOS 24)**, включая самые свежие прошивки, где закрыты старые уязвимости (*crashd*, *faultmanager*, *dejavuln*).

## 1. Преимущества Root-доступа

* **Вечный доступ без таймера 1000 часов:** официальный Developer Mode от LG требует продлевать сессию каждый месяц через приложение. Root навсегда отключает таймер — доступ остаётся навсегда.
* **Полноценный туннель Tailscale в ядре Linux (`tailscale0`):** без Root телевизор может использовать только локальный прокси (`127.0.0.1:1055`). С правами Root система поднимает виртуальный адаптер ядра `/dev/net/tun` — телевизор становится равноправным участником домашней сети.
* **Ультра-низкая задержка в Moonlight (4K 60/120 FPS):** Moonlight на телевизоре напрямую обращается к домашнему игровому ПК через Tailscale IP (`100.x.y.z`), обеспечивая минимальный инпут-лаг и аппаратное декодирование.
* **Каталог приложений Homebrew Channel:** установка YouTube без рекламы (с SponsorBlock), медиаплееров, ретро-эмуляторов RetroArch и любых неофициальных `.ipk`.
* **Постоянный доступ по SSH / Telnet (UID 0 - root).**

## 2. Необходимое оборудование и программы

1. **Телевизор LG Smart TV**, подключенный к домашней локальной сети (по Wi-Fi или кабелю LAN).
   * В нашем примере: IP телевизора `192.168.1.3`.
2. **Компьютер / Ноутбук** в той же локальной сети.
   * В нашем примере: IP компьютера `192.168.1.4`.
3. **Установленный Python 3.10+** на компьютере.
4. **webOS Dev Manager** (для удобного управления приложениями с ПК).

## 3. Подготовка рабочего окружения на ПК

### 3.1. Скачивание утилиты SlopBro
Создайте рабочую папку на ПК (например, `C:\TV\` или `E:\TV\`) и скачайте репозиторий **SlopBro** (автор *throwaway96*, эксплойт для уязвимости `jsserver`):

```bash
git clone https://github.com/throwaway96/slopbro.git E:\TV\slopbro
cd E:\TV\slopbro
```

### 3.2. Скачивание Homebrew Channel
Чтобы телевизор не зависел от внешнего интернета и не выдавал ошибок SSL-сертификатов при загрузке с GitHub, скачайте официальный установочный пакет Homebrew Channel и поместите его в папку `E:\TV\slopbro\wwwroot\`:

* Ссылка: `https://github.com/webosbrew/webos-homebrew-channel/releases/download/v0.7.3/org.webosbrew.hbchannel_0.7.3_all.ipk`
* Сохраните файл как: `E:\TV\slopbro\wwwroot\hbchannel.ipk`

### 3.3. Настройка списка раздачи файлов
Откройте файл `E:\TV\slopbro\slopbro.py` в любом текстовом редакторе и найдите список `SERVICE_FILES`. Добавьте в него `hbchannel.ipk`, чтобы он автоматически передавался на телевизор:

```python
ENTRY_PAGE = "index.html"
SHELL_SCRIPT = "autoroot.sh"
SERVICE_FILES = [
    "package.json",
    "main.js",
    "hbchannel.ipk",  # <-- Добавьте эту строку
]
```

Также откройте `E:\TV\slopbro\wwwroot\main.js` и обеспечьте вывод подробных ошибок (для полной прозрачности процесса):

```javascript
  try {
    const out = child_process.execFileSync("/bin/sh", [scriptPath].concat(args), { encoding: "utf8" });
    status = "success: " + out;
  } catch (err) {
    status = "error: " + err.message + "\nstdout: " + (err.stdout || "") + "\nstderr: " + (err.stderr || "");
  }
```

## 4. Пошаговое рутирование через эксплойт SlopBro

1. **Включите телевизор** и убедитесь, что он подключен к сети (проверьте IP-адрес в *Настройки ➔ Сеть*).
2. **Откройте терминал на ПК** в папке `E:\TV\slopbro` и выполните команду запуска:

```bash
python slopbro.py 192.168.1.3 --local-ip 192.168.1.4 --webos-version 5 --debug --curl-insecure
```
*(Замените `192.168.1.3` на IP вашего ТВ, а `192.168.1.4` на локальный IP вашего ПК)*

### Что будет происходить дальше:

* **Сопряжение (SSAP):** При первом запуске на экране ТВ появится запрос: *«Разрешить подключение устройства?»* — нажмите пультом **«Да»**. (Ключ авторизации сохранится на ПК в файл `192.168.1.3.key`).
* **Запуск эксплойта:** SlopBro поднимет локальный веб-сервер и через системное приложение (`com.webos.app.adoverlayex`) передаст полезную нагрузку.
* **Индикация на ТВ:** В углу экрана телевизора всплывут тосты:
  * `download started for autoroot.sh`
  * `downloading hbchannel.ipk: 100%`
  * `Installing...`
  * `Homebrew Channel has been elevated`
  * `Rooting complete`
* **Окно на экране ТВ:** Появится диалоговое окно:
  > *«Rooting complete. You may need to reboot for Homebrew Channel to appear. However, the Dev Mode app is installed. You must uninstall it before rebooting!»*

## 5. КРИТИЧЕСКИ ВАЖНО: Финализация после эксплойта

Это действие **строго обязательно** выполнить до перезагрузки:

1. **Удалите приложение «Developer Mode»:**
   * На пульте ДУ нажмите кнопку **Home** (домик).
   * В нижней ленте приложений найдите иконку **Developer Mode**.
   * Наведите курсор на иконку, зажмите центральную кнопку **OK** на 2 секунды (переход в режим редактирования) и нажмите значок **«Крестик / Корзина»** над иконкой Developer Mode.
   * Подтвердите удаление.
   > **Почему это важно:** Скрипт заблокировал системный флаг `/var/luna/preferences/devmode_enabled` навсегда. Но если оставить само официальное приложение Developer Mode, оно при истечении 1000-часового таймера попытается очистить папку приложений. Без него система остаётся с вечным полным Root-доступом.

2. **Перезагрузите телевизор:**
   * Нажмите кнопку **«Reboot now»** в диалоговом окне на экране ТВ (или просто выключите ТВ с пульта, подождите 5 секунд и включите снова).

После включения в ленте приложений появится иконка **Homebrew Channel**! 🎉

## 6. Настройка Homebrew Channel

1. Откройте **Homebrew Channel** в меню телевизора.
2. Перейдите в **Settings** (шестерёнка в верхнем правом углу).
3. Включите следующие опции:
   * **Root execution:** `ON` (включено)
   * **SSH Server:** `ON` (порт 22, логин `root`, пароль по умолчанию `alpine`)
   * **Telnet Server:** `ON` (порт 23, резервный доступ без пароля)
   * **Block software updates (Блокировка автообновлений):** `ON` — блокирует обращение к серверам обновлений LG, чтобы телевизор случайно не обновил прошивку и не стёр Root.
4. Нажмите **Install / Update** в главном меню Homebrew Channel, чтобы обновить каталог до актуального состояния.

## 7. Установка и запуск Tailscale (v1.104.8)

Для LG webOS разработана оптимизированная сборка Tailscale с поддержкой работы как без root, так и с полным root-доступом к ядру.

### 7.1. Установка пакета на ТВ
* Скачайте готовый пакет [com.tailscale.webos_1.104.8_all.ipk](https://github.com/neon1301/tailscale-webos/releases/download/v1.104.8/com.tailscale.webos_1.104.8_all.ipk) с GitHub Releases.
* Установите его через **webOS Dev Manager** (перетащите файл мышкой в окно программы) или через терминал SSH:
  ```bash
  ssh root@192.168.1.3 "luna-send -i 'luna://com.webos.appInstallService/dev/install' '{\"id\":\"com.tailscale.webos\",\"ipkUrl\":\"/tmp/tailscale.ipk\"}'"
  ```

### 7.2. Авторизация и включение
1. Откройте приложение **Tailscale** в меню телевизора.
2. На экране появится **QR-код**: наведите камеру смартфона, перейдите по ссылке и нажмите **«Connect / Log in»**.
3. Экран телевизора мгновенно обновится:
   * Статус: зеленый бейдж **«В сети (Online)»**.
   * Tailscale IP: постоянный адрес вида `100.x.y.z`.
   * Питание: **ВКЛ**, Автозапуск: **ВКЛ**.
4. Фоновая служба `com.tailscale.webos.service` автоматически прописывается в автозапуск при старте телевизора и поддерживает соединение 24/7.

## 8. Настройка Moonlight + Sunshine / DuoStream для игр с дачи

Это финальная цель: играть в игры с мощного домашнего ПК прямо на телевизоре на даче.

### 8.1. Установка Moonlight на телевизор
1. Откройте **Homebrew Channel** на телевизоре.
2. В строке поиска найдите **Moonlight** (Moonlight TV GameStream Client).
3. Нажмите **Install**.

### 8.2. Подключение к домашнему ПК
1. Убедитесь, что ваш домашний компьютер включен, на нём запущен **Tailscale** и настроен **Sunshine** или **DuoStream** (Tailscale IP, например, `100.66.187.32`).
2. Откройте **Moonlight** на телевизоре.
3. Нажмите кнопку **«Add Host»** (Добавить хост):
   * Введите IP-адрес Tailscale вашего домашнего ПК (например, `100.66.187.32` или с портом DuoStream `100.66.187.32:46300`).
4. Нажмите **Подключиться**. На экране ТВ появится **4-значный PIN-код**.
5. На ПК в панели управления Sunshine/DuoStream появится уведомление *«Pairing request»*: введите эти 4 цифры и нажмите **Pair**.
6. В меню Moonlight на телевизоре появится карточка вашего ПК со списком игр и рабочим столом (Desktop)!

### 8.3. Рекомендуемые настройки стриминга в Moonlight:
* **Resolution:** `1080p` или `4K (3840x2160)` (процессор телевизора аппаратно декодирует 4K HEVC без нагрузки).
* **Frame Rate:** `60 FPS` (или `120 FPS` для OLED 120Hz моделей).
* **Bitrate:** `40 – 60 Mbps` (для идеальной четкости без артефактов).
* **Video Codec:** `HEVC (H.265)` — максимальное качество при минимальном потреблении трафика.
* **Audio:** `Stereo` или `5.1 Surround`.
* **Gamepads:** Поддерживаются геймпады Xbox, PlayStation (DualShock / DualSense) и любые Bluetooth-контроллеры, подключенные напрямую к ТВ.

## 9. Решение возможных проблем (FAQ / Troubleshooting)

### В: Скрипт SlopBro пишет `[!] Another instance of this script is currently running (exit 2)`.
**О:** На телевизоре остался файл блокировки от предыдущего прерванного запуска. Подключитесь по SSH к ТВ и удалите его:
```bash
rm -f /tmp/autoroot.lock /tmp/autoroot.*
```

### В: При скачивании с GitHub на ТВ возникает ошибка `curl: (60) SSL certificate problem`.
**О:** Встроенные сертификаты на телевизоре устарели или дата рассинхронизирована. Всегда передавайте флаг `--curl-insecure` либо используйте предварительно скачанный локальный файл `hbchannel.ipk` в папке `wwwroot`, как описано в разделе 3.2.

### В: Нужно ли держать компьютер включенным после рутирования?
**О:** Нет. ПК нужен был только один раз на 30 секунд для запуска скрипта SlopBro. Дальше телевизор работает полностью автономно.

### В: Что делать, если изменился IP-адрес телевизора?
**О:** В настройках вашего домашнего Wi-Fi роутера рекомендуется закрепить постоянный локальный IP (Static DHCP lease) по MAC-адресу телевизора.
